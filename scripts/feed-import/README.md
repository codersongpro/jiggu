# 어필리에이트 상품 피드 가져오기

봇 차단이 걸린 브랜드(코치·마이클코어스·케이트스페이드·랄프로렌·라코스테 등)의 가격 데이터를
얻는 정공법이다. 스크래핑이 아니라 브랜드가 제휴사에 **공식적으로 제공하는 상품 피드**를 읽는다.

- 차단당할 일이 없다 (허가된 경로다)
- 정가·할인가·SKU·재고·이미지가 정리돼 있어 스크래핑보다 데이터 품질이 좋다
- 우리 앱의 원가 계산·게시글 생성 기능을 그대로 쓸 수 있다

## 1. 어디서 받나 — 네트워크 가입

브랜드마다 어느 네트워크에 입점해 있는지가 다르다. 아래 4곳이 주요 네트워크이고,
가입 후 각 네트워크 대시보드에서 **브랜드 이름을 검색해 제휴 신청**하면 된다.

| 네트워크 | 가입 주소 | 특징 |
|---|---|---|
| **Awin** | awin.com | 가입 시 소액 예치금(승인되면 환급). **API 키 없이** Toolbox의 Create-a-Feed로 CSV 피드 URL을 만들 수 있어 가장 간단하다 |
| **CJ Affiliate** | cj.com | 미국 브랜드가 가장 많다. 가입 후 developers.cj.com에서 Personal Access Token 발급 |
| **Rakuten Advertising** | rakutenadvertising.com | 미국·일본 브랜드. Publisher 가입 후 Links > Product Feed에서 다운로드 |
| **Impact** | impact.com | 가입 후 Account > API Access에서 Account SID / Auth Token 발급 |

### 순서

1. 네트워크에 **Publisher(퍼블리셔/제휴사)** 로 가입한다. 운영 중인 채널 정보를 요구하는데,
   네이버 카페(해바라기)를 채널로 적으면 된다.
2. 네트워크 승인이 나면, 대시보드에서 원하는 **브랜드(Advertiser)에 개별 제휴 신청**을 한다.
   브랜드별로 심사가 따로 있고, 승인돼야 그 브랜드 피드에 접근할 수 있다.
3. 승인된 브랜드의 **상품 피드(Product Feed)를 CSV/XML로 다운로드**한다.

> **API 키가 꼭 필요한 건 아니다.** 이 스크립트는 다운로드한 파일을 읽으므로,
> 대시보드에서 CSV를 내려받는 것만으로 충분하다. API 키는 매일 자동으로 받아오게
> 만들 때 필요하고, 그건 다음 단계 작업이다.

### 미리 알아둘 것

- 브랜드별 승인은 거절될 수 있다. 특히 대형 럭셔리 브랜드는 심사가 까다롭다.
- 어필리에이트 피드는 원래 "제휴 링크로 판매를 유도"하라고 주는 데이터다.
  가격 참고용으로만 쓸 계획이라면 각 네트워크 약관을 한 번 확인하는 게 안전하다.
- 한국 거주자도 대부분 가입 가능하지만, 일부 브랜드는 특정 국가 트래픽만 받는다.

## 2. 변환하기

```bash
node scripts/feed-import/import-feed.js <피드파일> [옵션]
```

| 옵션 | 설명 |
|---|---|
| `--brand "Coach"` | 피드에 브랜드 컬럼이 없을 때 브랜드명 강제 지정 |
| `--shop "코치 (제휴피드)"` | 구입처 표시 이름 (기본: 파일명) |
| `--region US\|EU\|JP` | 보통 통화로 자동 판별된다 |
| `--sale-only` | 할인 중인 상품만 남긴다 |
| `--business` | 사업자 사입 모드로 원가 계산 (기본: 구매대행) |
| `--limit 500` | 최대 상품 수 (기본 1000) |
| `--map "name=제목,salePrice=판매가"` | 컬럼 자동 인식이 실패했을 때 직접 지정 |

지원 형식: CSV, TSV, 파이프 구분, Google Shopping/RSS XML.
CJ·Rakuten·Awin·Impact가 쓰는 흔한 컬럼명은 자동으로 맞춘다. 실행하면 어떤 컬럼을
어디에 매칭했는지 출력하니, 틀렸으면 `--map`으로 고치면 된다.

```
형식: CSV · 행 1204개
컬럼 매핑:
  name         → product_name
  brand        → brand
  salePrice    → sale_price
  listPrice    → retail_price
  ...
```

**통화 제한**: `config/cost.yaml`이 USD/EUR/JPY만 다루므로 GBP 등 다른 통화 상품은 건너뛴다.
영국 피드가 필요하면 `cost.yaml`에 GBP 환율·배송 요율을 먼저 추가해야 한다.

## 3. 앱에 넣기

변환 결과는 `scripts/feed-import/output/feed-<타임스탬프>.json`에 저장된다.
앱의 **설정 탭 → 로컬 크롤링 결과 가져오기**에서 이 파일을 열면 상품 탭 목록에 합쳐진다.
같은 구입처로 다시 가져오면 그 항목만 교체된다.
