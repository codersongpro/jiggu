    수집 결과 가져오기

    Shopify가 아닌 사이트(REI·BEAMS 등)는 PC에서 npm run crawl -- --source rei-us --limit 20 --output output/rei-us.json으로 수집하고, 제휴 피드는 npm run feed-import -- <피드파일>으로 변환합니다. 만들어진 JSON을 여기서 열면 상품 탭 목록에 합쳐집니다 — 다른 판매처·브랜드로 이미 가져온 상품은 지워지지 않습니다. 형식이 맞지 않으면 반영 전에 거부하고 기존 데이터를 유지합니다.

    계산 설정

    계산 설정을 불러오는 중…

    세율·관세·배대지 요율은 서버의 config/cost.yaml에서만 관리합니다 (/api/config로 받아 씁니다). 세금·배송 조건이 검증되지 않은 시장(예: 영국)은 원문 가격만 표시하고 원가는 "계산 미완료"로 남습니다.

    연결 상태

    'Sale중' 탭의 스캔 버튼을 누르면 /api/scan?scope=sale이 config/targets.json에 등록된 모든 활성 판매처의 세일 컬렉션을 한 번에 5곳씩 조회하고, 화면이 다음 위치(cursor)를 따라가며 이어붙입니다. 상품 탭의 조회는 판매처 한 곳의 한 페이지씩 전체 목록을 읽습니다. 끝까지 이어받은 범위만 "완전 수집"으로 처리하므로 중간에 실패해도 기존 목록이 지워지지 않습니다. 상품명은 영문 원문 그대로 표시되니 게시글 작성 시 다듬어 쓰세요. 전일 대비 세일 변화(신호)는 스캔 기록이 쌓여야 표시할 수 있어 이번 버전에서는 제공하지 않습니다.
